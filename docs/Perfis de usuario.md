## Visitante

Usuário não logado.

Pode:

- ver vitrine pública;
- buscar figurinhas;
- visualizar detalhes básicos;
- acessar tela de cadastro/login.

Não pode:

- comprar;
- vender;
- reservar;
- acessar painel.

___

## Usuário cadastrado

Pode:

- comprar figurinhas disponíveis;
- anunciar figurinhas para venda ao administrador;
- acompanhar seus próprios pedidos;
- acompanhar suas próprias ofertas;
- editar dados básicos da conta.

Não pode:

- ver ofertas de outros usuários;
- alterar preço;
- alterar estoque;
- acessar dados administrativos.

___

## Administrador

Representa o filho do Claudecir/Schumacher.

Pode:

- gerenciar catálogo;
- gerenciar estoque próprio;
- configurar preços;
- ver ofertas recebidas;
- aceitar ou recusar ofertas;
- gerenciar pedidos;
- confirmar pagamento presencial;
- alterar status de pedidos;
- consultar relatórios;
- gerenciar usuários, se necessário.
