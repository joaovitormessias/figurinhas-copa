## Área pública

### Página inicial

- lista de figurinhas disponíveis;
- busca;
- filtros;
- preço;
- botão “Tenho interesse” ou “Comprar”.

### Detalhe da figurinha

- imagem;
- código;
- nome;
- seleção;
- preço;
- disponibilidade;
- botão de compra.

### Login/cadastro

- cadastro;
- login;
- recuperação de senha.

---

## Área do usuário

### Meus pedidos

- lista de pedidos;
- status;
- valor;
- itens.

### Vender figurinha

- busca no catálogo;
- seleção da figurinha;
- quantidade;
- estado;
- observação;
- envio da oferta.

### Minhas ofertas

- ofertas enviadas;
- status;
- resposta do administrador.

---

## Área administrativa

### Dashboard

- pedidos pendentes;
- ofertas pendentes;
- estoque baixo;
- vendas concluídas;
- compras realizadas.

### Catálogo

- cadastrar;
- editar;
- ativar/desativar;
- importar.

### Estoque

- adicionar figurinha ao estoque;
- alterar quantidade;
- alterar preço;
- marcar como visível/invisível.

### Pedidos

- visualizar;
- alterar status;
- registrar pagamento;
- cancelar.

### Ofertas

- visualizar ofertas dos usuários;
- aceitar;
- recusar;
- registrar compra;
- adicionar ao estoque.

### Configurações

- preço padrão de compra;
- preço padrão de venda;
- dados de contato;
- mensagem padrão para pagamento presencial.
