## Objetivo

Criar um sistema web no subdomínio:
```
figurinhas.schumachertursc.com.br
```

O sistema deve funcionar como uma **vitrine pública de figurinhas disponíveis para compra**, mas com uma regra central:

> O público só visualiza e compra as figurinhas vendidas pelo Administrador do sistema.  
> As figurinhas anunciadas por usuários externos aparecem apenas para o administrador, que decide se compra ou não.
