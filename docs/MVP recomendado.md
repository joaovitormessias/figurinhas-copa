## Versão 1

1. Cadastro/login.
2. Catálogo manual de figurinhas.
3. Cadastrar todas as figurinhas por **código/número**.
4. Criar card visual próprio com CSS.
5. Vitrine pública.
6. Estoque do administrador.
7. Pedido de compra simples.
8. Oferta de venda do usuário para o administrador.
9. Painel admin básico.
10. Status manual.
11. Pagamento presencial registrado manualmente.

## Não colocar no MVP

- carrinho complexo;
- chat;
- cupom;
- frete;
- integração WhatsApp;
- ranking de raridade;
- marketplace entre usuários;
- pagamento online.
